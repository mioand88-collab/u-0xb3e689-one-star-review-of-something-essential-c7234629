# One-Star Review of Something Essential

A deadpan one-star review of the sun — an everyday essential that shows up
uninvited every morning, stays all day, and charges us for the sunscreen it
makes necessary. Written as a flat product complaint about a thing nobody can
live without.

Running `main.ts` writes the single-line review to `/output/entry.txt`.
